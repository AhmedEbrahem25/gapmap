# Demo script and slides

## Demo script

The step-by-step demo script is maintained in one place, next to the code it drives:
**[../../demo-script.md](../../demo-script.md)**. It covers set-up, accounts, the 9 storyboard steps
from plan Section 18 with what to say and click, and what to do if something breaks.

## Slides

The pitch deck has 12 slides with speaker notes: problem, how it works, why not a chatbot, live
demo, what the demo shows, trust rules, where AI fits, architecture, testing, honest limits,
closing. It is a Claude artifact; teammates need it shared with them to open it:
https://claude.ai/artifact/UoMkzu79ka7w1dVLPH76dX

To produce `Slides.pdf` for this folder: open the deck → **Share** → **Export** → **PDF**, and save
it here as `Slides.pdf`. Replace the `[Team names]` placeholder on slides 1 and 12 first.
